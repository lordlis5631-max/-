Как заниматься

Один блок — один подход. Задания с пометкой «Повторение» проверяют существительное.

На каждый ответ — две попытки. После первой ошибки появляется подсказка, после второй — объяснение.

Прогресс сохраняется в браузере. Для учителя можно скачать текстовый отчёт.
