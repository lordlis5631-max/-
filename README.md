# Форум «Конструктив.Действуй» — интерактивная карта ПФО

Современный мобильный сайт для сбора и обсуждения региональных профилактических решений. На интерактивной карте представлены все **14 субъектов Приволжского федерального округа**, с подписями непосредственно на карте.

## Структура сайта

- Карта с названиями регионов, поиском, выбором территории и масштабированием жестами.
- Шесть вопросов: тенденция или проблема; кому нужна поддержка; где проявляется; чего не хватает; факторы риска; на какие ресурсы можно опереться.
- Блок лучших региональных профилактических практик: описание, ссылка на презентацию.
- Контакты для сотрудничества: ФИО, социальная сеть, номер телефона.
- Доступное редактирование через кнопку-карандаш с подтверждением изменений и дополнительной защитой от случайного удаления.
- Локальная история последнего изменения с возможностью восстановления.
- Адаптивная верстка для телефонов.

## Как внести изменения

1. Откройте регион.
2. Нажмите на значок карандаша возле вопроса, практики или контактов. Подтвердите запрос на редактирование.
3. Внесите данные и нажмите «Сохранить ответ». Подтвердите сохранение.
4. Изменения будут сохранены только в **локальном хранилище этого браузера**. До модерации другие посетители их не увидят.
5. Для публикации нажмите **Отправить на публикацию**. Сайт подготовит предложение в GitHub Issues. Для отправки требуется аккаунт GitHub.
6. Владелец репозитория проверяет текст и в GitHub Issues добавляет метку **publish-approved**. Если такой метки ещё нет, её нужно однократно создать в **Issues → Labels**.
7. GitHub Actions выполняет файл `scripts/publish_issue.py`, валидирует заявку и обновляет `content-data.js`. После опубликования новой версии сайта сведения станут видны всем.

**Важно:** предложения в GitHub Issues общедоступны сразу после отправки. Получайте согласие контактного лица на публикацию ФИО, телефона и ссылок.

## Что лежит в репозитории

- `index.html` — структура страницы.
- `styles.css` — внешний вид и адаптация к мобильным устройствам.
- `site.js` — интерактивная карта, вопросы, редактирование и отправка предложений.
- `map-data.js` — географические контуры 14 субъектов.
- `regions.js` — названия и административные центры.
- `content-data.js` — утверждённые и публично доступные ответы.
- `scripts/publish_issue.py` — безопасная обработка одобренных предложений.
- `.github/workflows/publish-region.yml` — публикация по одобрению администратора.

Географические данные: [russian-geo-data](https://github.com/antibioticbook/russian-geo-data), лицензия CC0. Контуры упрощены для визуальной навигации.
